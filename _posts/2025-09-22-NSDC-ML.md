Happy Monday!

Over the past two weeks, I have been working on the [Data Science Project, Movie Reveiw Sentiment Analysis](https://nebigdatahub.org/nsdc-data-science-project-sentiment-analysis/).  It's been a much shorter form project than the last one I've done, and I've already started Milestone 4 of 4.  THe goal of the project is to learn using Natural Language Processing and Machine Learning to perform sentiment analysis on IMDB reviews.  I'm glad to be returning to learning Python and using Python notebooks.  I had loved Microsoft OneNote for a good part of my life, though I'm using ObsidianMD now, so learning about Jupytr, Google Colab, and Kaggle blew my mind!  

Milestones 1 and 2 were pretty straightforward.  It started with getting familiar with importing libraries and giving a brief overview on Pandas and NLTK.  I had learned and used Pandas in previous classes, but this was my first time with NLTK, which is a natural language processing library for Python.  Milestone 2 delved deeper into NLTK, performing tokenization (breaking down a longer string into smaller units), stop word removal (cleaning words that are considered noise in text such as the, he, her, etc.), and stemming (extracting the root word from a given word ("code" from coding, coded, etc.).

Milestone 3 walked through the steps of Machine learning using sklearn and trainng a Naive Bayes classifier.  The learning mostly took the form of filling in the blanks in existing code or writing a new line of code based on previous ones.  In the last project, there were videos to go along with each milestone, which I think I would have appreciated especially here.  I think I struggle with learning code through filling in the blanks, especially when I don't have a solid foundation yet.  I was able to get through the steps with some troubleshooting and got a result.  I think I am getting a better handle on the steps to perform the splits for testing and training data.

Milestone 4 I think is really starting to highlight some of my knowledge gaps.  I know that coding can sometimes be heavy in terminology, but machine learning seems to be especially dense in this regard.  The goal of Milestone 4 is to essentially complete the same steps as 3, but researching and using a different classifier (and therefore different sklearn functions).  Doing the research of which classifier to start with really took some time, and the guidance that the project provided was to read the sklearn documentation, which seems to assume that you have a grasp on Machine Learning already.  It took me a good amount of time reading and Googling to settle on a plan.  

I decided that I'm going to try to do this with 3 classifiers, Nearest Neighbors (which seems to be what most algorithms are built off of), Decision Trees (which seem like another "simple" classifier), and Support Vector Machines.  Stumbling through attempting the Nearest Neighbors, I think the most valuable thing (whether I do this right or not) is that I can learn the differences in both how to code with these classifiers, and how the results differ.  There is also a part of me that may table this project and look for a class or resources that can provide a good baseline for understanding machine learning.

"That's all" for now, have a great week!
