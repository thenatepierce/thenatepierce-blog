Hello hello!

I can't believe have already gone by.  On my last post, I mentioned that I don't believe I have enough foundational knowledge to complete the NSDC Machine Learning project in a meaningful (to me) way.  I don't believe I fully understand all of the inner workings, and working through the final step, I was going through a loop of seeing a term, finding the definition, seeing that the definition is using a term I'm not familiar with, find that definition, so on and so forth.  Taking a quick look at the Harvard CS50 series, I see they have a course on AI and Machine Learning with Python.  I had a really great experience with their Intro to Python, so I think this will help close the gap!

I was able to get through Week 0, which already explained some things that I had ran into, but didn't fully grasp.  I struggled a bit on the first problem, but that was also sort-of self inflicted.  The goal was essentially to complete a program to determine how many degrees of separation are between two actors, referring to an IMDB database.  Most of the program had been completed, but the problem was to create a function to perform the search algorithm itself.  My biggest issue is that I just started coding without putting too much thought into planning.  This came back to bite me, because I hadn't consider how the written main function (which I was not permitted to modify) was expecting my output.  This made the problem take much longer to complete than it really needed to, but we got there!

The second problem of Week 0 is to make a Tic Tac Toe game, including an AI that attempts to perform the most optimal move.  It provided a python script that will run the actual game and instructed what functions it would like me to create.  Learning from my past mistakes, the first thing that I did was go through each function, create a comment with the assignment's requirements for that function, and then another comment section that includes my notes on what I think the function needs to have created, where and how it is called in the runner script provided, if this function will need to be called in any other functions, and then from there, a todo list.  It may be a bit overdoing it for an assignment, but I think this is going to save me some headache in the long run and I think this is going to be good practice for the future, where in the real world, I'm probably more often going to be working on code started by others or working on code with others.

That's it for now, I hope to have an update here once I make more progress on the problem or complete.

Until next time!
