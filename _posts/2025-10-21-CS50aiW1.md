Happy Tuesday!

I was able to wrap up week 0 of Harvard's CS50ai course.  Last time I mentioned that when working through the second problem, I went through the code, did some note taking for each function which included what was the input, where the function may be called, what is the expected output, and lastly how I may go about coding the function.  This allowed me to create a useful todo list for each function.  Though it took me a couple hours to go through all 7 functions, and the notes may have been more thorough than necessary, the actual coding process went (mostly) smoothly!  I was able to knock out the code and testing it without that much troubleshooting, which felt really refreshing.  Previously, I would write something, tested it, fixed it, rinse and repeat until I made the next batch of code.  It was nice to just code and see things coming together almost immediately.  It also broke up the process into more manageable chunks.  Beforehand I would just code until I was satisfied in stopping /and/ had a reasonable breakpoint.  Knowing what needed to be done ahead of time allowed me to have reasonable stops and breaks as well!  Overall, I think learning the lesson in the first problem and then applying and feeling the benefit in the second problem was incredibly useful to me.

Week 1 is tackling providing knowledge to a program in a way that it can understand and act upon.  It started off with different logic symbols and meanings, which, where I have a background in Math and Philosophy, it was kind of nice to already be pretty familiar with logic tables.  This let me focus on how those logic principles interact with programming and the ideal workflow.  The two problems for this week are one for word logic puzzles and one for minesweeper.  I've started mapping out my notes for the first one, and will have more updates here as I progress!

Until next time!
